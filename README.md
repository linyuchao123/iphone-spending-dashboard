# 消费有迹

一个为 iPhone 优先设计的个人消费记录与可视化面板。它可以作为网页 App 添加到 iPhone 主屏幕，在手机与电脑之间同步账本，并在断网时继续记账。

> 在线站点：[xiaolin-spending-trace.lyc20260327.chatgpt.site](https://xiaolin-spending-trace.lyc20260327.chatgpt.site/)（需要使用已授权账号登录）

## 项目特点

- **快捷记账**：支持微信零钱、微信银行卡、支付宝花呗、支付宝银行卡、校园卡余额和银行卡支付。
- **多周期统计**：分别查看今天、本周、本月和本年的支出、趋势、渠道、分类与流水。
- **年度月份下钻**：在本年趋势图中点击任意月份，查看该月的完整消费统计和记录。
- **日期段明细**：点击本月趋势中的日期段或本周趋势中的某一天，直接筛选对应流水。
- **消费统计**：按类型、具体内容和商家/用途查看消费排行，点开商家可查看常买内容与消费流水；支持全部、本年、本月范围。
- **消费热力图**：使用类似 GitHub 的年度热力图展示每日消费强度，颜色越深代表支出越高。
- **官方账单导入**：支持导入微信、支付宝解压后的 CSV 消费明细，自动过滤收入、退款和失败交易，并进行去重。
- **离线优先**：新增、修改和删除会先保存在本机；网络恢复后自动补传。
- **跨设备同步**：iPhone 主屏幕版、Safari 和电脑网页使用同一账号时共享同一份云端账本。
- **数据可控**：支持 JSON 完整备份、CSV 导出，以及撤销最近一次账单导入。

为统计“在某家店常买什么”，手工记账时可填写“消费内容”（例如鸡腿饭、拿铁）。新导入的官方账单会尽量从商品说明中提取；旧账单在没有独立商品字段时会使用原先保存的商品说明或备注，未记录具体内容的历史流水仍可按分类和商家查看。

## iPhone 使用方式

1. 使用 Safari 打开在线站点。
2. 点击 Safari 底部的“共享”按钮。
3. 选择“添加到主屏幕”。
4. 打开“作为网页 App 打开”，再点击“添加”。

之后可以像普通 App 一样从桌面启动，不会显示 Safari 地址栏。无网络时仍可记账，恢复网络后会自动同步。

## 账单导入说明

本项目不会直接读取微信、支付宝或银行卡账户，也不具备支付、转账或提现能力。账单数据来自用户主动选择的官方导出文件：

1. 在微信或支付宝中申请并下载官方账单。
2. 如果得到 ZIP 文件，先在 iPhone“文件”App 中解压。
3. 在“消费有迹”的“同步与数据”页面选择其中的 CSV 明细文件。
4. 核对预览结果后确认导入。

## 同步机制

每次新增、修改、删除和设置变更都会生成独立同步操作。客户端先更新本机界面并写入持久化待同步队列，然后在以下时机尝试同步：

- 网络恢复时；
- 页面回到前台时；
- 重新打开网页 App 时；
- 定时检查时。

服务端按修订版本返回增量变化，并通过操作 ID 去重。删除记录会保留删除标记，避免其他离线设备把旧记录重新上传。

## 技术栈

- Next.js 16 / React 19 / TypeScript
- Vinext + Vite
- Cloudflare Workers 兼容运行时
- Cloudflare D1 + Drizzle SQL migrations
- Service Worker、Local Storage 与离线同步队列
- OpenAI Sites 托管

## 隐私与边界

- 站点只提供消费记录的查看、录入、编辑、删除、导入与导出功能。
- 不保存支付密码，也不请求微信、支付宝或银行卡的支付权限。
- 云端账本按登录账号隔离；未登录或使用不同账号时无法读取原账号数据。
- 浏览器本机仍会保留缓存和待同步队列，建议定期导出 JSON 完整备份。
